# GemCrashの画像素材

図柄、枠、筐体をImageGenの組み込みツールで個別に生成した。透過PNGを `GemCrash/assets/art/` に保存した。配信用の画像は透過を保って縮小している。

## GemCrashの効果音

プロジェクトのルートで `node GemCrash/tools/generate-audio.mjs` を実行すると、`GemCrash/assets/audio/` の6ファイルを同じ波形で再生成する。周波数、音価、減衰は生成スクリプト、音量と同時発音数は `GemCrash/audio.mjs` で変更できる。

| ファイル | 音の設計 | 発動 |
| --- | --- | --- |
| `spin.wav` | 低く回る駆動音と短い振動 | 回転開始 |
| `stop.wav` | 金属と木の感触を狙った短い打音 | 各列の停止 |
| `match.wav` | 短いガラス質の二声。連鎖段階に応じて再生速度を上げる | 実際に成立した通常のかたまり |
| `land.wav` | 低めの短い衝撃音 | 補充の盤面を表示 |
| `orb.wav` | 高い倍音を段階的に重ねた輝き | レインボーオーブのかたまりが成立 |
| `win.wav` | 短い3段の上昇音型 | 今回の差引がプラスで確定 |

Gonzo’s Questの石材の着地、Sweet Bonanzaで観測された連鎖音の上昇、Book of Deadの制作資料にある場面ごとのキューの分離を参考に、鉱物工房の題材で波形を作った。ゲームの「効果音」で有効にでき、音量も調整できる。音声ファイルの形式、長さ、ピーク、キューの条件は試験済み。実機のスピーカーでの聴感と画面との同期は試遊で確認する。
