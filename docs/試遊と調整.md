# 試遊と調整

## 起動

`slot/` を開いて `node scripts/preview.mjs` を実行し、ブラウザで `http://127.0.0.1:8080/` を開く。停止するときは端末で Ctrl+C。ポートを変える場合は、たとえば `node scripts/preview.mjs 8081` とする。

## 確認する操作

| ゲーム | 確認する操作 |
| --- | --- |
| GemCrash | 1・5・10のベット、列ごとの回転と停止、消去と連鎖、結果へ、配当明細、練習盤面、10回転チャレンジ、初期無音と効果音 |
| Vault Reels | 図柄の保留と解除、引き直し、そのまま確定 |
| Route Reels | 左端からの選択、上下に1段ずれた接続、選び直し |
| Star Reels | 図鑑への登録、完成した星座の配当、12回転終了、再開 |

## 変更箇所

- 表示するゲーム、説明、公開ファイルは `games.json` で管理する。掲載を取りやめるときは対象の登録だけを外せば、ソースを残したまま一覧と配信対象から外せる。
- SlotHubの見た目はルートの `style.css`、GemCrashの宝石色と盤面は `GemCrash/style.css`、追加3ゲームの見た目は `shared/reels.css` で変更する。
- GemCrashの宝石、ワイルド確率、配当は `GemCrash/simulator/presets/6x7.json`。クレジット初期値と選べるベットは `GemCrash/session.mjs`。
- GemCrashの図柄、枠、筐体の画像は `GemCrash/assets/art/`、効果音は `GemCrash/assets/audio/` にある。生成の指示と再生成手順は [素材制作](GemCrash/素材制作.md) を参照。
- 追加3ゲームの図柄、抽選の重み、役の配当は `shared/reels.mjs`。星座の必要図柄と配当は `StarReels/game.mjs`。
- 音を追加する場合はゲーム内の `assets/` などに置き、音を鳴らす操作をゲーム側で指定する。配信対象は `games.json` のゲームごとの `files` に登録する。

## 再検証と配信準備

```powershell
node --test GemCrash/simulator/engine.test.mjs GemCrash/session.test.mjs GemCrash/game.test.mjs GemCrash/audio.test.mjs scripts/reels.test.mjs
node GemCrash/simulator/simulate.mjs GemCrash/simulator/presets/6x7.json
node scripts/build-site.mjs _site-review
```

配信準備コマンドには未使用の `_site-...` 出力名を指定する。GitHub Pagesのワークフローは配信用ファイルだけを集める。
