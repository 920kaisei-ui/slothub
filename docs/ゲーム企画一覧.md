# SlotHub ゲーム企画一覧

1. **Vault Reels（保留と引き直し）**  
   3リールを回してから、残したいリールを選び、残りを1回だけ引き直す。最初の出目をそのまま確定する選択肢もある。ペアをキープするか、配当の高い図柄で3つ揃いを狙うかを毎回決められる。評価では、同じ出目から保留の選択によって異なる展開になるかを見る。
2. **Route Reels（出目でルートを選ぶ）**  
   3列×3段の出目から、隣の列へ1段以内の移動で左から右へ進む。同じ図柄がつながるルートを選び、2つ以上つないで確定する。カードの選択順に応じて次へ進めるマスを示す。評価では、盤面によって最善のルートが変わり、行き先を見比べられるかを見る。
3. **Star Reels（期間内の図鑑完成）**  
   12回転で星座を完成させる。払い出しを受け取ったうえで、その回転に出た星を1種類だけ図鑑に登録できる。複数の星座が同じ星を必要とするため、完成間近の星座や残り回転数から選ぶ。評価では、終了時に集めた星と完成した星座が分かり、次の回は別の狙いを立てられるかを見る。

各企画は独立したブラウザゲームとして実装する。遊びの起点は、連鎖や役の成立、各回転での選択、短い目標の達成。結果と配当表を表示し、架空クレジットを使う。公開後の収益化を検討する場合は、広告表示や外観・音源などの追加コンテンツを候補にする。
